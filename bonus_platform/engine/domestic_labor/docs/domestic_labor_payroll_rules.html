国内劳务薪酬四个已配置科目规则梳理

基于当前平台代码实际逻辑整理，用于和业务部门、线下核算规则逐条比对。

当前范围：全勤奖 / 餐补 / 外宿补贴 / 工龄奖 分支：codex/domestic-labor-payroll 代码点：1ada9a4 生成日期：2026-06-22

1. 数据入口与通用处理

平台按员工逐行读取月报/月考勤，并把同一员工的日考勤、住宿名单记录分组后传给各科目引擎。

适用于四个科目

月报 / 月考勤

系统优先查找工作表名包含 月报 或 月考勤 的 sheet。若未找到，则取第一个 sheet 作为月度主表。

每一行代表一个员工，是四个科目的主输入。

日考勤

系统查找 sheet 名包含 日 或 日考勤 的表，并按 工号 分组。

主要用于全勤奖入职缺口判断、餐补逐日计算、外宿补贴是否全月未出勤。

住宿名单

系统查找 sheet 名包含 住宿 的表，并按 工号 分组。

仅外宿补贴使用，用于扣除住宿重叠天数。

通用处理 系统当前逻辑 对线下规则比对时要关注
数值字段标准化 月报字段如 排班天数、正班出勤天数、旷工天数、事假时数、病假时数、实际在职工作日天数 等会转为数字；空值转为 0。 线下表若用公式但没有缓存值，平台可能读到 0；需确认上传文件是否已计算保存。
日期字段标准化 入职日期、最后工作日、转正日期 会转为日期；空时间 00:00 视为空。 日期格式异常会影响全勤奖、外宿补贴、工龄奖。
缺勤字段回填 若月报缺勤字段为 0/空，系统会尝试从日考勤汇总：正班旷职 → 旷工时数、事假 → 事假时数、病假时数 → 病假时数、排休请假 → 排休请假时数。 工龄奖优先读取 旷工时数、排休请假时数；仅缺少小时字段时，才按对应天数字段 × 8 折算。
入离职缺勤时数推导 若 入离职缺勤时数 为 0/空，解析层会按 (排班天数 - 实际在职工作日天数) × 8 回填；工龄奖引擎内部也按同一公式计算。 平台不是直接按 最后工作日 推导当月入离职缺勤，而是依赖排班天数和实际在职工作日天数。
结果结构 每个科目输出金额、明细、结构化异常、审计解释；总额为四个科目相加。 平台异常分为阻断、警告、提示；提示类不一定阻止发放。

2. 全勤奖

固定金额科目，当前标准为 100 元/月。只要命中任一排除条件，金额为 0。

科目字段：quanqinjiang

标准与总公式

默认标准：100 元/人/月。

全勤奖 = 满足全部发放条件 ? 100 : 0

涉及表和关键字段

月报/月考勤日考勤

工号、姓名、考勤月份、入职日期、最后工作日、旷工天数、正班迟到次数、早退次数、签卡次数、工伤假天数、事假时数、病假时数、入离职缺勤时数、迟到早退30分钟内扣款。

日考勤用于判断非月初入职员工在入职前缺口内是否存在工作日，字段包括 出勤日期、工作状态。

判断顺序 条件 结果 线下比对要点
1 工号在特殊排除名单：OWHN9535、OWHN9353、OWHX0190。 全勤奖 = 0。 确认线下是否存在同一特殊名单。
2 考勤月份 不是 6 位 YYYYMM。 全勤奖 = 0，返回月份异常。 确认导入表月份格式。
3 任一异常考勤命中：旷工天数 > 0；正班迟到次数 + 早退次数 > 3；签卡次数 > 3；工伤假天数 > 0；事假时数 > 0；病假时数 > 0；入离职缺勤时数 > 0；迟到早退30分钟内扣款 > 0。 全勤奖 = 0。 确认线下是否把工伤假、事假、病假、入离职缺勤都作为全勤奖直接排除。
4 非月初入职，且月初至入职日前存在工作日。优先按日考勤 工作状态 判断；无日考勤记录时按自然周一至周五判断。 全勤奖 = 0。 确认线下是否按工作日历或排班日历判断入职前缺口。
5 无 最后工作日，或最后工作日为空。 全勤奖 = 100。 在职员工通过前序排除后发放。
6 最后工作日 不早于考勤月月末。 全勤奖 = 100。 离职日期在月末或之后仍视为当月在职至月末。
7 最后工作日 早于考勤月月末。 全勤奖 = 0。 确认线下当月离职是否直接无全勤。

4. 外宿补贴

按地区岗位资格、当月在职区间、住宿名单和缺勤时数折算。

科目字段：waisu_butie

涉及表和字段

月报/月考勤日考勤住宿名单

月报字段：工号、姓名、考勤月份、入职日期、最后工作日、事假时数、排休请假时数、病假时数、旷工时数、入离职缺勤时数；嘉善/义乌还读取休年假及婚假、陪产假、工伤假等有薪假字段。

日考勤字段：上班一、下班一。

住宿名单字段：工号、入住时间、退宿时间；兼容工作表名 宿舍名单 以及字段别名 入宿时间、离宿时间。

标准与总公式

规则外宿补贴标准：150 元/月；上传文件中的 外宿补贴标准 不参与资格或金额计算。

常规地区：外宿补贴 = 标准 / 当月天数 × 有效补贴天数 晋江：外宿补贴 = 标准 - 入离职扣款 - 请假扣款
步骤 系统当前逻辑 结果影响
月份校验 考勤月份 必须为 6 位 YYYYMM。 格式异常则外宿补贴 = 0。
全月未出勤判断 如果有日考勤记录，但该员工没有任何 上班一 或 下班一 打卡。 视为全月未出勤，外宿补贴 = 0。
资格判断 按工作地区、岗位和线下名单判断：东莞排除不享有岗位，嘉善/义乌/晋江按享有岗位名单判断，东莞支持姓名特批；嘉善/义乌享有名单包含数据专员、保洁和操作文员。 资格不满足时外宿补贴 = 0；上传文件中的补贴标准字段不参与判断。
当月在职区间 在职开始 = max(入职日期, 月初)；在职结束 = min(最后工作日, 月末)，最后工作日为空则为月末。 在职天数小于等于 0 时外宿补贴 = 0。
住宿扣除 若住宿名单命中工号，按实际入住时间、退宿时间计算住宿区间与当月在职区间的重叠天数；退宿当天开始享有外宿补贴，不计入住宿扣除。 住宿扣除天数从外宿补贴天数中扣除。
基础补贴天数 外宿补贴天数 = max(在职天数 - 住宿扣除天数, 0)。 用于常规折算。
缺勤折算 东莞仅全月在职员工进入缺勤折算；嘉善/义乌当月入离职员工也进入。缺勤时数合计 ≥ 56 且无住宿扣除时，按 基础补贴天数 - 缺勤时数 / 8 计算有效天数。 否则按基础补贴天数计算，避免住宿扣除和缺勤重复扣。
晋江扣减 入离职扣款按自然日折算；当月有 最后工作日 时只扣最后工作日后的自然日，没有最后工作日时才扣当月入职日前自然日。请假旷工天数超过 7 天才扣请假。 用于晋江月考勤扣减公式。

缺勤时数口径

东莞缺勤时数 = 事假时数 + 排休请假时数 + 病假时数 + 旷工时数 + 入离职缺勤时数

东莞按 5 月实际核算口径：病假小时按 100% 计入；休年假、婚假、陪产假、工伤假等有薪假不计入 56 小时。

嘉善/义乌按华东线下月考勤公式：婚假、陪产假、工伤假等各类请假天数及排休请假天数按 8 小时折算，并计入休年假、事假、调休、哺乳假和旷工；病假小时按 60% 计入。当月入离职员工也执行 56 小时判断。

金额保护

如果计算结果小于 0，系统会把金额置为 0，并提示“补贴天数为负，请人工复核”。

司龄计算

参考日期为 考勤月份 的当月 1 日。按入职日期到参考日期计算完整年数，不足 1 年为 0。

工龄年数 = floor(考勤月1日 - 入职日期 的完整年)

若入职日期不是有效日期，工龄奖 = 0，异常等级为阻断。

正班出勤为 0 的处理

正班出勤天数为 0 且存在事假时，按线下工资表人工归零口径，工龄奖为 0；仅病假等其他缺勤仍按公式折算。

异常码：ZERO_REGULAR_ATTENDANCE_DAYS，等级：提示。

折算项目 系统公式 触发条件 / 说明
事病旷排休时数 事假时数 + 病假时数 + 旷工时数 + 排休请假时数；缺少小时字段时按对应天数 × 8。 若合计 ≥ 56 小时，按出勤天数比例折算；否则应发金额全额保留。

请假折算后金额 日折算金额 × (排班天数 - 事病旷排休时数 / 8) 仅当事病旷排休时数 ≥ 56 小时时执行。
入离职缺勤时数 (排班天数 - 实际在职工作日天数) × 8 不直接按最后工作日计算，依赖月报排班与实际在职工作日字段。
入离职折算后金额 请假折算后金额 - 日折算金额 × 入离职缺勤时数 / 8 入离职缺勤时数大于 0 时扣减。
最终舍入 Excel ROUND(折算后金额, 2) 按线下公式四舍五入，不额外设置最低 0 元兜底；请假折算后可能为负数。
