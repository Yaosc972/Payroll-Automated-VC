开始本月核算

打开平台对应页面 ↗
01新建本月核算活动活动列表 → 新建核算活动
  1. 选择奖金所属月份，默认上月。例如 10 月操作时，默认核算 9 月；回算历史奖金时可选择更早月份。活动名称可留空，按所属月份自动命名。
  2. 上月只有一份确认结果时自动选中承接；有多份时选择本次对应的一份。首次迁入时导入上月核算表，作为已发、未发及暂缓奖金的起点。
  3. 点击“创建并进入”，进入“导入资料”。
处理结果本月资料和核算记录保存在该活动中。同月可有多个活动，进入前核对活动名称和月份。

进入活动后，一键同步国内及海外资料，上传本月特批，查看核算明细并处理待办。首次历史核算需要已有核算表作为奖金起点；确认本月结果后，下月继续承接。

接续上月尚未结清的奖金首次使用，确实没有历史未结奖金
02继续已有核算或切换核算记录活动列表 → 进入核算；活动内标题旁 → 核算记录
  1. 在活动列表按名称、月份或状态查找，点击活动名称或“进入核算”。
  2. 同一活动有多份核算记录时，点击“核算记录”，选择月度核算或指定的历史记录。
  3. 查看页面月份和记录名称后继续操作。切换活动请使用“返回活动列表”。
处理结果已保存的资料和修改继续保留。关闭页面不会完成月末确认。
确认本月核算结果改活动名称、归档和恢复活动
03接续上月尚未结清的奖金导入资料 → 上月核算表
  1. 新建活动时已选择上月确认结果的，等待资料整理完成，查看是否显示“已承接上月”。
  2. 需要从线下迁入时，上传可信的上月核算表。点击“采用上月表”；有多份候选表时，只选择本次应承接的一份。
  3. 点击“确认采用并更新核算”，返回明细核对历史人员、未结分期和原安排。
处理结果上月核算表用于接续历史奖金。仅用于比较的“线下核对表”不作为上月基础。

历史已锁定的分期不能直接重排。若选错上月表，从核对事项或文件详情重新核对采用来源。

首次使用，确实没有历史未结奖金上月确认结果后来发生变化将某一期奖金改到指定月份
04首次使用，确实没有历史未结奖金导入资料 → 上月核算表 → 没有历史未结奖金
  1. 核实本次核算范围内没有往月未发完、暂缓或待补发的奖金。
  2. 点击“没有历史未结奖金”，再点击“确认没有历史未结奖金”。
  3. 导入本月花名册和招聘资料。
处理结果本月从无历史未结奖金的基础开始核算。

存在历史未结奖金时，应导入上月核算表。

接续上月尚未结清的奖金导入花名册、Offer、离职资料和特殊审批

导入与补充资料

打开平台对应页面 ↗
05导入花名册、Offer、离职资料和特殊审批导入资料 → 导入资料
  1. 选择本月花名册及招聘资料，可分次、多文件导入，也可拖入工作区。支持页面列出的 Excel、PDF 和图片格式。
  2. 等待资料整理完成。平台按文件内容归入“本月花名册”“国内招聘资料”“海外 Offer”“离职与特殊审批”等分类。
  3. 查看每份文件的状态；有读取失败或待处理提示时，打开文件核对。随后点击“查看核算明细”。
处理结果识别到的资料用于匹配人员并更新核算；原文件保留。合并花名册能覆盖人员范围时，无需拆成固定份数。

文件已上传不等于人员已全部识别。同名文件不保证覆盖旧文件；相同内容重复上传也不会补出缺失资料。

查看原件、搜索工作表或下载文件一批人员缺少录用信息文件读取失败、未识别或导入后没有新增人员
06导入体系外同事提供的本月核定结果导入资料 → 体系外核算结果；调整数据 → 体系外核算结果；待办与差异 → 体系外结果事项
  1. 点击“下载模板”，填写被招聘人、奖金项目、领取人、本月核定金额和币种。奖金项目填写招聘负责人奖金、协助招聘人奖金或内推奖金。已有人员编号、入职日期和领取人编号可以一并提供。
  2. 点击“上传结果”，选择本月表格。也可上传原核算台账，平台只提取标注体系外、GL 或已确认体系外范围的奖金项目。已有待采用预览时，点击“继续处理”，无需重新上传。
  3. 核对预览中的人员、领取人、金额及按币种合计。出现同名或多次任职时，在该行选择对应任职；缺少金额等内容时，按工作表、行号和字段提示更正表格后重传。正常行不需要逐人审阅。
  4. 点击“采用 N 项”，正常结果一次采用。尚未解决的行保留在“继续处理”中，关闭窗口后仍可从同一卡片继续。
  5. 返回“核算明细”，核对“体系外线下核定”项目及招聘奖金、内推奖金汇总。更正结果时上传更正版，核对“更正后替换”记录后采用。
处理结果本月采用已分配给实际领取人的核定金额，不再按招聘周期、比例或内部任职资料重算；同一项目不会与自动核算重复计奖。

金额空白表示缺项，0 表示明确不发。暂缓金额不计入本月发放合计。重复上传相同结果不会重复计奖；更正版替换本月对应项目，原件与版本保留。体系外范围和人员对应关系可承接至下月，仅提示本月应处理项目，不沿用上月金额。

误传资料，停用或恢复文件核对招聘奖金汇总和内推奖金汇总开始下月，承接本月已确认结果
07查看原件、搜索工作表或下载文件导入资料 → 文件名
  1. Excel 文件可切换工作表、搜索姓名或工号，并翻页查看记录。PDF 或图片可查看原页。
  2. 点击“下载原件”保存该文件。资料列表可在“列表”和“网格”两种显示方式间切换。
  3. 需要查看同步详情、审批记录或文件参与状态时，展开文件预览中的“更多”。
处理结果原件查询用于核实录用、任职和审批内容，不会修改核算。
一键同步国内及海外资料误传资料，停用或恢复文件识别审批调整，核对后采用
08发现漏人，补充一名员工导入资料 → 手动补充人员
  1. 先在“核算明细”切换“全部人员”，按姓名或工号搜索，确认不是筛选条件隐藏了该员工。
  2. 确实未纳入时，点击“手动补充人员”，填写姓名；已知的工号、入职日期、招聘负责人工号一并填写。
  3. 点击“保存人员”，再通过“调整数据 → 修改人员资料”补齐影响奖金的事实。多人遗漏时，补充花名册或录用名单后整批导入。
处理结果新增人员进入核算记录；资料不完整的奖金仍需补充后才能确定。

候选人暂缺工号可以保存，不要编造工号。已有人员应修改原记录，避免重复新增。

修改入职、转正、离职、职级或渠道等资料查不到员工、无工号、重复姓名或任职未匹配
09一键同步国内及海外资料导入资料 → 一键同步国内及海外
  1. 选择核算月份，点击“一键同步国内及海外”，自动读取两边的花名册、关联 Offer 及任职记录，同时补查历史人员及领取人的任职资料。
  2. 查看国内、海外两项同步进度；需要时可点击“停止”。单边失败会保留已取得的资料，可重新同步。
  3. 打开已保存快照，核对花名册、录用及任职资料；实际缺项按待办补齐。
处理结果新活动首次同步可建立人员底稿；已有核算再次同步时，按月另存快照供核对，原结果和待办保留。特殊审批继续线下导入。

同步保存原始接口快照和带生效日期的任职记录，按奖金适用日期核对在职、转正资格。同日冲突、日期缺失及与已留存资料不一致的事项进入核对。回算历史月份需保留当时的核算表、Offer 和特批依据；接口中的历史记录可能经过事后更正，不能据此推定已发金额或宣称历史结果已核验一致。

同一招聘负责人、协助招聘人或推荐人影响多人国内查询失败、查询无记录或返回资料不全
10一批人员缺少录用信息待办与差异 → 核对事项 → 对应的录用资料事项
  1. 打开事项，查看具体缺项。多项信息已有唯一参考值时，点击“带入表中已有信息”；也可逐项选择表中值，并查看来源单元格。
  2. 已有内容核对后采用，无需再次上传。真正缺少的内容可上传录用资料，或下载补充表补齐后上传。
  3. 国内人员可使用事项中的“接口补查”。只有少量字段需要修改时，点击该人员的“手工补充”，查看修改结果后保存。
处理结果能够匹配的人员整批更新；尚缺资料的人员继续保留待办。

默认先处理影响本月的人员；后续月份人员可展开查看。不需要把花名册中已有字段重新填一遍。

不同资料中的日期、渠道或人员信息不一致查看后续月份需补的资料
11不同资料中的日期、渠道或人员信息不一致待办与差异 → 核对事项 → 对应事项
  1. 打开事项，核对同一员工、同一次入职的原始资料。需要时展开“从原始资料选择”。
  2. 选择正确来源值，或直接填写本次采用值。只修改已核实的字段。
  3. 点击“查看修改结果”，核对受影响人员、本月金额及分期变化，再点击“确认保存”。
处理结果平台保存采用值并重新核算；原始资料仍可查。未解决的缺项继续显示。

普通修改无需另填依据文件、页码和修改原因。周期剔除等专门业务字段仍按具体事项维护。

修改入职、转正、离职、职级或渠道等资料招聘周期异常、负周期或需要剔除天数二次入职、内部调动或用工关系变更
12误传资料，停用或恢复文件导入资料 → 文件名 → 更多
  1. 核对文件内容和当前参与状态，错误文件点击“停用”。需要重新使用的文件点击“恢复”。
  2. 等待核算更新，再检查受影响的人员、待办和调整记录。
  3. 已经作为上月基础的文件，应先核对正确的上月来源，不能按普通补充文件处理。
处理结果停用保留原件和历史记录，但不再按有效资料使用；恢复后重新参与核算。

停用被审批或更正引用的资料，可能使相关事项转为待重新核对。

接续上月尚未结清的奖金已做的补扣、例外或差异结论又提示需重核

查看核算结果

打开平台对应页面 ↗
13查看一名员工的奖金为什么这样计算核算明细 → 员工姓名
  1. 按姓名或工号搜索，核对入职日期；有多次入职记录时选择本次任职。
  2. 在“奖金明细”查看招聘奖金、内推奖金的适用规则、总额、币种、招聘周期及各期安排。
  3. 在“员工资料”查看采用的事实；在“原始资料与修改记录”查看来源和更正。需调整时点击“调整数据”。
处理结果可以对应到具体奖金、招聘负责人／协助招聘人／推荐人及发放月份。
区分零金额、待核金额和未安排奖金修改入职、转正、离职、职级或渠道等资料将某一期奖金改到指定月份
14核对招聘奖金汇总和内推奖金汇总核算明细 → 招聘奖金汇总／内推奖金汇总
  1. 招聘奖金汇总按领取人及币种查看；内推奖金汇总按推荐人及币种查看。同一人领取不同币种奖金时分行列示，可搜索姓名或工号。
  2. 核对本月各阶段金额、补发／扣回、待核金额和合计，按币种查看。
  3. 清除搜索条件后查看完整汇总；需要追查某笔金额时返回核算明细查看员工分期。
处理结果页面汇总与本月核算表使用同一份核算结果。

各币种分别合计，不自动换汇。

区分零金额、待核金额和未安排奖金下载本月核算表币种不同，或明细与汇总看起来不一致
15区分零金额、待核金额和未安排奖金核算明细 → 员工姓名 → 奖金明细
  1. 金额为 0 时，查看不享受、资格不符、未到期、取消或暂缓等具体原因。
  2. 显示“待核对”“待补充”或金额待定时，进入关联核对事项，先补齐影响计算的信息。
  3. 有奖金总额但本月未安排时，查看对应分期的到期日、安排月份及资格。
处理结果明确是规则计算为零、尚不能确定金额，还是奖金安排在其他月份。

待核不等于零，也不等于可以发放；尚未核实的金额不能当作已核对汇总。

按事项处理核对事项将某一期奖金改到指定月份候选人或领取人离职、推荐人未转正，仍需发放
16查找人员、定位字段和调整表格显示核算明细；调整数据 → 批量修改 → 在表格中编辑
  1. 日常明细可切换“本月核算人员”“需要核对的人员”“全部人员”，并通过字段组定位表格位置。
  2. 进入完整明细后，可切换“核算明细”“完整台账”“各人分期”“人员与依据”“线下原表数据”等列视图。
  3. “列设置”可勾选字段并保存视图，也可恢复默认。表头支持排序、拖动非固定列和调整列宽。
  4. 日常明细和汇总的列边界可拖动，双击边界适配单列；点击“自动列宽”按当前页内容重排并清除本表手动列宽。内容被省略时，将鼠标停在该单元格查看完整显示值。
处理结果仅改变当前浏览器的查看方式，不改变奖金，也不改变主导出文件的范围。

姓名、工号是固定列。“线下原表数据”需已有对应历史台账。

直接编辑表格或粘贴 Excel 区域多人修改为同一个值

修改人员与招聘分工

打开平台对应页面 ↗
17修改入职、转正、离职、职级或渠道等资料调整数据 → 修改人员资料
  1. 选择调整事项后搜索员工；也可先搜索员工，再选择“修改人员资料”。核对姓名、工号和入职日期。
  2. 在“修改项目”中搜索要改的字段，填写“修改为”。多项更正点击“＋ 再改一项”；也可展开“按类别添加多项”。
  3. 点击“查看修改结果”。确认字段、本月金额和涉及人员正确后，点击“确认保存”；需要修改则点击“返回修改”。
处理结果更正自动保存并更新奖金，原值和修改记录保留。

将已填写字段改为空白属于清空；“移除”只移除本次要提交的修改项。规则计算金额应通过奖金调整处理，不直接覆盖。

更换招聘负责人或协助招聘人更换推荐人或补充推荐关系多人修改为同一个值查修改记录，撤销或重做更正
18更换招聘负责人或协助招聘人调整数据 → 更换招聘负责人／协助人
  1. 选择候选人，分别搜索新的招聘负责人、协助招聘人，核对姓名和工号。
  2. 确实没有协助招聘人时勾选“无协助招聘人”。需要从文件带入时，展开“从原始资料带入分工”，选文件并点击“带入分工”。

术语含义
核算活动按月份和业务范围保存资料、核算结果及处理记录的一项工作。
核算记录同一活动内的月度记录或另建的重新核算记录；处理前确认当前打开哪一份。
候选人／员工这笔招聘或内推业务对应的入职人员，不一定是奖金领取人。
招聘负责人／协助招聘人／推荐人分别对应招聘奖金和内推奖金的领取角色；页面部分位置统称“领取人”。
上月核算表／期初用于接续上月未结奖金的基础。部分工具和字段仍使用“期初”一词。
奖金总额按该员工适用规则计算的奖金总额，与本月安排金额不同。
分期／奖金节点一笔奖金的具体发放阶段，包含金额、领取角色、到期日和安排月份。
规则到期日／安排月份前者由适用规则确定；后者表示当前安排计入哪个核算月。
待核对／待补充资料或规则条件尚未明确；不是已计算出的零金额。
暂缓／不发／扣回暂缓保留奖金待后续安排；不发取消指定奖金资格或角色范围；扣回登记应扣减金额。
资格例外／判断日期资格例外只处理指定分期的特定条件；判断日期决定本月某类奖金统一按哪一天核对在职、转正。
体系外线下核定按体系外同事提供的当月结果核算，金额已分配到实际领取人，平台不再套用自动核算规则。
已保存／已确认／实际支付已保存是修改已入底稿；已确认是本月结果已认可；实际支付以工资执行结果为准。
