# FBU美洲绩效核算平台设计文档

## 一、项目概述

### 1.1 背景
FBU美洲大区每月需要核算员工绩效奖金，目前通过Excel手动计算，流程复杂、易出错、耗时长。

### 1.2 目标
构建一个"规则配置 + 数据处理 + 自动核算 + 异常校验 + 审计解释 + 审批发放"的薪酬计算中台。

### 1.3 核心用户
**薪酬专员**：每月核算绩效奖金，需要查看明细、导出报表、处理异常。

### 1.4 核心场景
**月度核算**：从OEHR导出数据 → 分步核算 → 导出结果 → 提交审批。

### 4.1 异常类型

| 数据缺失 | 考勤有但薪资无 | 高亮标记，弹窗确认 |
