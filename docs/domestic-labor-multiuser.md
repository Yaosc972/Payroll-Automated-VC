# 中国区外包工薪酬核算：多人活动

基于生产整合提交 `8607a29d` 开发，保留自离名单、交互规则包及对象存储直传功能。

- 复用平台登录身份；创建人由服务端确定。
- 活动服务端保存，包含科目、月份、名称、创建人及核算任务关联。列表仅展示活动名称、科目、月份、创建人、状态、更新时间和进入入口，不展示异常数、员工数或应发合计；支持我的/全部、名称或创建人搜索、科目、月份、状态筛选和分页。
- 所有已获得模块访问权限的用户均可查看活动、核算明细及下载结果；提交、修改和删除只作用于本人活动，防止相互覆盖。
- 夜班配置及晋江名单按用户和月份保存；已完成核算保留当时配置快照。远程存储启用时配置及历史版本同步持久化。
- 核算任务与文件保持独立目录；列表指标从核算结果读取，不接受浏览器提交金额和创建人。使用远程存储时状态以远程记录为准，避免不同实例展示过期状态。
- 历史服务端核算记录仍可查看，未记录创建人的显示为历史活动，不自动认领。旧浏览器 localStorage 的未提交草稿不自动迁移，原数据不会删除。
