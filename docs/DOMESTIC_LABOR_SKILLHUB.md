# 中国区外包工薪酬 SkillHub

入口：`/domestic-labor-skillhub.html`。中国区外包工薪酬核算顶部导航提供 SkillHub 链接；页面及下载沿用国内核算模块的权限。

SkillHub 当前维护餐补、外宿、夜班、岗位、高温、全勤、工龄七份独立 Skill。支持搜索、分类、版本详情、单包下载、全部下载及上新动态。参考目录组织：[skills.sh](https://skills.sh/)、[ClawHub](https://clawhub.ai/)。

页面使用紧凑目录：宽屏每行四张卡片，窄屏自动减少列数；卡片保留科目、简介、版本及下载，完整规则在详情中查看。上新提醒集中在算薪页顶部入口，SkillHub 不再展示独立的“最新上新”推广区域，历史记录仍可通过“上新动态”查看。

## 权威来源

- 核算逻辑：`bonus_platform/engine/domestic_labor/engines/`。
- 已确认业务规则：同目录的 `rule_package.py`。
- 独立输入契约、脚本与填写工作流：`skillhub_assets/`。
- 生成与同步：`skillhub.py`；不要手工修补生成的 ZIP。
- 随代码保存的发布记录：`skillhub_assets/releases.json`。

包内保留科目规则版本、独立包版本、内容指纹和原始源码 SHA-256。Git HEAD 变化不会单独触发上新，规则版本号未变但实际包内容变化会触发上新。ZIP 与工作簿时间戳规范化，相同内容的重建结果一致。

包不包含平台上传文件、员工活动数据、环境配置、会话或密钥。历史规则中已经确认的资格及名单条款属于规则快照，保持原口径。夜班使用本月明确确认的配置，不读取平台存储；随包历史班次基线不代表本月已确认配置。

## 更新规则后的同批操作

修改业务引擎或规则后，同时检查输入契约、填写说明及独立 runner 是否需要适配。先完成针对性测试，再运行：

```bash
python3 -m pytest -q tests/test_domestic_labor_skillhub.py
python3 -m scripts.domestic_labor_skillhub_release
```

脚本默认生成 `outputs/domestic-skillhub-latest/` 内的七个 ZIP 和一个总包，并更新随代码保存的发布记录。已经存在的内容不会重复上新；新发布记录、业务规则、打包器和输入契约应在同一批代码交付中保留。不要只更新 ZIP 或只改页面文案。

页面 API 每次读取当前引擎、规则和包内容，按内容指纹同步最新版本。无需手工修改页面卡片；变化会形成“XXX Skill 上新”记录，30 天内展示新版本标签。运行时记录保存在平台输出目录的 `domestic_skillhub/catalog.json`，首次由随代码发布记录初始化。共享环境发布仍需正常部署；线上实例不会自动读取本地未部署代码。临时运行环境跨实例的完整历史以随代码保存的发布记录为准。

曾下载的包保持原有快照，须重新下载使用新版本。带版本指纹的旧下载链接在内容变化后返回 409，避免用户拿到与页面版本不一致的文件。

## 首页上新提醒

算薪页顶部 SkillHub 入口显示带感叹号的“科目 Skill 上新”角标，多个未读版本显示最近更新的科目及其余数量，悬停可查看完整科目。按 Skill 内容指纹判断更新，不受页面样式调整或 30 天展示期限影响。点击入口（包括键盘及新标签页打开）后，仅将已读取的版本标为已读；后续新版本再次提醒。

已读状态按当前用户保存在此浏览器的 localStorage，同一浏览器内刷新、返回、其他标签页会同步；其他浏览器或设备分别记录。目录请求失败时隐藏角标，不影响核算操作。

## 页内使用指引

SkillHub 的“使用指引”页签与顶部同名入口展示两组对话：原始资料检查后核算，以及从原始资料重新核算并逐人核对线下结果。支持七个科目切换，核算月份默认上个月；从科目详情进入时选中对应科目。科目与月份保留在页内链接，刷新可恢复。

核算、核验、补齐资料、导出四类提问可直接复制，内容随科目和月份改变，并读取当前 Skill 的资料清单。对话人物、表格金额和文件名是示例，复制的提问不包含演示人员或金额。下载按钮指向当前科目最新包；手机上对话纵向排列。

维护位置：`static/domestic-labor-skillhub-guide.js`。实际资料清单来自 SkillHub catalog，特殊缺项与补充说明在该文件中维护；契约变更时应同步检查指引文案。运行方式以包内 SKILL.md、输入契约与 workflow.md 为准。

## 图标与选择组件

下载、详情、使用指引、复制和关闭使用统一的 SVG 线性图标。科目图标与算薪首页保持一致。公共组件维护在 `static/domestic-labor-skillhub-ui.js` 和同名 CSS 中，不依赖外部 CDN。

排序和科目菜单展示当前选中项及勾选，支持方向键、Home／End、Enter、Escape 和 Tab；月份面板提供年份切换、12 个月和“上个月”快捷选择。原始字段保留值与 change 事件，切换科目或月份后更新指引并恢复控制按钮焦点。菜单随屏幕宽度定位，点击外部或滚动时关闭，尊重减少动画设置。
