# 职场搬迁补贴

中国区正式工薪酬核算新增子模块。入口选择月份后点击“开始核算”，弹窗展示科目和月份；点击“确认并开始”后自动进入工作台并核算，取消或按 Esc 不发起核算。服务在后台读取北森月报、月报关联任职、员工姓名和组织层级，按规则试算并保存批次，可查询明细、筛选、回看及导出 Excel。运行中阻止重复提交。

核算页仅显示活动名称、月份、进度及结果操作，不重复展示月份选择器或规则长文。历史记录统一进入三个科目共用的活动列表，详见 `china-payroll-activities.md`。加载区随后台进度更新读取考勤、匹配任职、核对并生成结果三步，使用本地 GSAP 3.15.0 分别呈现考勤扫描、档案配对、组织树核对和明细生成四种 SVG 场景及结果入场。后端 progressDetail 提供当前阶段、已处理数、总数与单位；前两步的百分比与分段进度条仅按真实计数更新，最后一步将组织核对和明细生成合并为处理状态，不显示百分比或进度条，总量未知时显示等待状态，不估算整体百分比。实际耗时以批次创建时间计算。失败停止动画并提供重试；完成后收起进度区，异常说明在有待核对项时展开。支持系统减少动态效果设置，离开页面或切到后台时停止循环动画。

月份可选择 2000～2099 年；默认选择上个月，只有选中月份显示蓝色高亮；当前月使用无描边的中性灰并标注“当月未结束”，未来月保留虚线及文字标签。未来月份可提前选择，能否核算以北森是否已有月报为准，无月报时返回暂无数据提示。状态按上海时间更新，页面重新获得焦点、恢复可见或跨月后的分钟检查会刷新状态，不改变用户已选月份。

## 本地运行

沿用项目 FastAPI 启动方式，打开 `/china-employee-payroll.html#relocation-allowance`。

凭据从既有 `BEISEN_APP_KEY`、`BEISEN_APP_SECRET` 环境配置读取；macOS 未设置时复用社保报盘的 Keychain 条目 `beisen-social-insurance-key` 和 `beisen-social-insurance-secret`。密钥和 token 不进入浏览器、批次文件或日志。

接口：

- `POST /api/china-employee-payroll/relocation-allowance/runs`，请求 `{"month":"2026-08"}`；返回 202 与批次 ID。
- `GET .../runs`：最近 30 个批次。
- `GET .../runs/{runId}`：进度、错误或完成结果。
- `GET .../runs/{runId}/export`：带样式的 XLSX，文本单元格显式写为文本，避免公式注入。第一张表为职场搬迁补贴结果，第二张为本批次部门范围内的原始考勤快照；旧批次缺少快照时明确提示重新核算。文件名使用中文月份、ABU职场搬迁补贴与批次计算完成时间。

北森月报每页 100 条、最多 4 个并发读取，临时连接错误自动重试；仍超时的页尝试用两页 50 条读取同一区间。取数总数改变、分页不完整、月报月份不一致或同一员工出现多条月报时终止，避免给出部分结果。

## 运行范围

当前实现面向单进程本地服务，运行中任务在同一进程内防重复启动，批次位于系统临时目录 `sigma_workbench_relocation_runs`。重启后未完成的旧批次显示中断。临时文件不是永久业务台账。

本轮没有修改鉴权、数据库、部署配置或生产连接。现有中国区薪酬接口未纳入海外劳务模块的鉴权路径；生产部署前须明确访问控制、服务器北森凭据、持久存储和后台任务运行方式。
