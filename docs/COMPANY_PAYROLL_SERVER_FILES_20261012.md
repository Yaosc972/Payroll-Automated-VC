# 公司正式工文件传输适配 — 2026-10-12

用户选择正式工模块与公司国内劳务、FBU 一致，由工作台服务器转交文件，不新增 OBS CORS。变更仅在公司集成工作区；Vercel 分支未修改。

## 行为与边界

- 当正式工持久化已启用且既有文件后端为 OBS/S3，上传配置返回 `directUpload=false`；现有网页自动将 WX Excel 作为 multipart `attendance_files` 提交到活动 `/start`。
- 服务器检查文件数（1–20）、扩展名、单文件 50 MB 和总计 100 MB，计算长度与 SHA-256，将输入保存到既有私有对象存储，全部成功后才写入 MySQL 输入清单并入队。Worker 再次验证长度和 SHA-256 后核算。网络文件写入在线程池执行，不占用数据库事务。
- 开始请求重试读取既有运行/完成任务；上传失败不会替换原输入清单或开始新任务。
- 集团、WX 和 ABU 的导出接口从私有 OBS 读取已保存的 Excel，检查长度/SHA-256，再返回同源附件响应及中文文件名。浏览器不取得公司 OBS 签名链接；公司直接上传入口返回明确的 409。
- 非公司存储后端沿用原直传/签名下载。活动、任务表、租约、权限、模块范围、创建人、核算规则和历史命名空间不变，无新增环境变量或数据库结构。
