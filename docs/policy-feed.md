# 政策资讯试接入

首页抽屉读取 `/api/workbench/policies?q=&offset=0`，仅已登录用户可用。查询不触发外部抓取。列表展示官方标题、发布日期和原文；不生成政策解读、不推断生效日期、不更改核算规则。地区标签表示来源所属地区，不替代政策适用范围。

## 来源及覆盖

来源清单：`bonus_platform/engine/policy/sources.json`。当前配置 15 个来源：原有国家医保局，北京、广州、深圳的公积金与社保来源，以及上海社保来源；新增山西、黑龙江、江苏、河南、湖南、广东、陕西省级医保来源。2026-09-28 本地实采 14 个来源检查成功，上海社保来源仍无可解析文章链接。检查成功可以包含零篇符合条件的文章，不等于有近期更新。每个来源仅抓取当前列表页中最多 20 篇匹配文章，尚不代表完整历史库，也未覆盖全国全部城市。403、重定向、列表解析无结果、部分详情失败均记录为异常，不表示没有新政策。失败时保留已有文章和上次完整成功时间。

全国候选目录：`bonus_platform/engine/policy/national-directory.json`，来源为国家医保局官方地方医保网站目录 `https://www.nhsa.gov.cn/col/col28/index.html`，包含 31 个省级医保部门及新疆生产建设兵团。目录入口经过本地访问检查；能读取首页仍可能只返回动态页面，因此 `needs_adapter` 不代表已接通。`adapter_verified` 仅表示该日期已完成当前栏目采集验证；`unreachable` 表示本次请求失败。快照不是持续健康监控，最新已启用来源状态以数据库 `policy_source_checks` 为准。未纳入 `sources.json` 的候选不会被定时采集。此目录不覆盖各市县人社、公积金等全部部门，不能宣称全国全部政策覆盖。

扩展城市时核验官方域名、列表地址、文章路径模式、发布日期元数据，并完成真实采集验证。不得绕过网站访问控制。公告正文不存储；链接及标题去重键为规范化官方原文 URL 的 SHA256。

## 上线顺序

1. 在目标环境使用现有管理库连接配置，执行 `python3 -m scripts.policy_feed migrate`。新增独立 `policy_articles` / `policy_source_checks` 表，重复执行安全；Web 请求不会自动建表。使用现有 SQLite / PostgreSQL / MySQL 连接适配器。生产需要持久化数据库，不能依赖 Vercel 的 `/tmp` SQLite。
2. 在独立初始化任务中执行 `python3 -m scripts.policy_feed refresh --all` 完成首次采集，核对逐来源结果。此命令不修改用户或薪酬表；全量模式不用于有时长限制的 Web 请求。
3. 随应用发布新增接口与静态文件。`vercel.json` 已声明每日 `00:30 UTC`（北京时间 08:30）调用 `/api/policies/cron/refresh`，复用 `CRON_SECRET` Bearer 验证，未设置密钥时拒绝调用。不要将密钥写入代码。
4. 验证 Vercel 调度实际启用，并检查一次执行结果和来源状态。代码中声明计划不代表已部署或调度已运行。

首次开发仅操作显式指定的本地试验数据库，未执行生产迁移或部署。定时请求如本批全部来源异常返回 503；部分成功返回 `partial`。不会清空历史数据。默认刷新按最久未检查排序，每次最多 8 个来源；失败来源也记录检查时间，避免阻塞其他来源。每来源顺序请求，最多 8 个来源并行，单请求超时 8 秒、响应限制 2 MB。现有每天一次的调度下，15 个来源需两次运行才能轮询一遍，并非所有来源每天更新。若继续增加来源，应先配套提高调度频率或使用独立采集 worker；生产配置本次未启用。当前没有分布式任务锁，同一环境应仅使用一个调度入口，URL 幂等入库能防重复文章但不能防重复网络请求。

默认列表和关键词/类型查询均只展示最近 180 天（含边界）且不晚于当前北京时间日期的文章。旧记录保留在数据库，不因发布时间直接标为失效。招聘、采购、个案催缴及标题明确标注已失效/已废止的记录不显示；此规则不代表已完成政策法律效力审查。

企业人事相关性：采集和查询共用标题规则，优先收录缴费/缴存、参保增减员、费率、退休、生育待遇、工伤办理等主题；剔除医药行业监管、药品、医用设备、居民专属政策等。规则只依据标题，可能漏掉标题不明确的相关政策，需要定期人工复核；不代表已对正文作出业务适用性判断。

征求意见稿、诊疗项目及医疗机构制剂目录暂不进入正式政策资讯；详情页完整标题会再次校验，避免列表截断标题误收录。官方页面的发布日期可能是补录或重发时间，不代表政策生效日期或文件制定年份。
