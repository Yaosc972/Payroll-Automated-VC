# 生产环境技术栈切换逻辑

本文档说明 Sigma-Workbench 在**本地开发**与**生产环境**之间的数据库和存储后端切换规则。

---

## 概览

系统三层存储各有本地/生产两套方案：

| 层级 | 本地开发 | 生产环境 |
|------|---------|---------|
| Run 元数据 | SQLite 文件 | MySQL |
| Admin 权限 | SQLite 文件 | MySQL |
| Labor Job 队列 | 本地 JSON 文件 | MySQL |
| 劳务文件存储 | 本地磁盘 | OBS（华为云） |

---

## 1. 数据库后端切换

### 1.1 Run 元数据（招聘奖金核算批次记录）

**文件：** `bonus_platform/engine/local_store.py`

**切换规则：**

```
如果 ADMIN_DATABASE_URL 以 "mysql://" 开头 → MySQL
否则 → SQLite (outputs/sigma_workbench.db)
```

**关键代码：**

```python
# local_store.py:52-53
def _is_mysql() -> bool:
    return _admin_database_url().startswith("mysql://")
```

```python
# local_store.py:48-49
def _admin_database_url() -> str:
    return (os.environ.get("ADMIN_DATABASE_URL") or os.environ.get("DATABASE_URL") or "").strip()
```

**MySQL 连接（local_store.py:83-99）：**
- 驱动：`pymysql`
- 从 URL 解析 host / port / user / password / database
- 字符集：`utf8mb4`
- 游标类型：`DictCursor`

**SQLite 连接（local_store.py:112-115）：**
- 数据库文件路径：`config.DATABASE_PATH` = `outputs/sigma_workbench.db`
- 自动建目录（`mkdir(parents=True, exist_ok=True)`）

### 1.2 Admin 权限管理

**文件：** `bonus_platform/engine/admin_store.py`

**切换规则（admin_store.py:301-314）：**

```python
def _database_backend(db_path: Path | None = None) -> str:
    if db_path is not None:
        return "sqlite"                          # 显式传入路径 → SQLite
    database_url = get_admin_database_url().strip()
    if not database_url:
        return "sqlite"                          # 空 URL → SQLite
    if database_url.startswith(("postgres://", "postgresql://")):
        return "postgres"                        # Postgres URL
    if database_url.startswith("mysql://"):
        return "mysql"                           # MySQL URL
    if database_url.startswith("sqlite://"):
        return "sqlite"                          # 显式 SQLite URL
    raise RuntimeError(...)                      # 不支持的 scheme → 抛错
```

**各后端连接方式：**

| Backend | 连接函数 | 驱动 | 特殊处理 |
|---------|---------|------|---------|
| `sqlite` | `sqlite3.connect()` | 标准库 | `PRAGMA foreign_keys = ON` |
| `postgres` | `psycopg.connect()` | psycopg | `SELECT pg_advisory_xact_lock(917137)` 互斥锁 |
| `mysql` | `pymysql.connect()` | PyMySQL | `SELECT GET_LOCK('sigma_admin_schema_init', 5)` 互斥锁 |

**SQL DDL 对应关系：**

| Backend | 常量名 | 表结构 |
|---------|--------|--------|
| SQLite | `SQLITE_SCHEMA` | `admin_users`, `admin_roles`, `admin_user_roles`, `admin_modules` |
| Postgres | `POSTGRES_SCHEMA` | 同上，Postgres 语法 |
| MySQL | `MYSQL_SCHEMA` | 同上，`ENGINE=InnoDB DEFAULT CHARSET=utf8mb4` |

**表结构说明：**

| 表名 | 用途 |
|------|------|
| `admin_users` | 管理员用户信息（含飞书 open_id / union_id） |
| `admin_roles` | 角色定义（system admin / module owner 等） |
| `admin_user_roles` | 用户-角色关联 |
| `admin_modules` | 功能模块注册 |

**Admin 数据源优先级（admin_store.py:296-298）：**

```
1. config.ADMIN_DATABASE_URL（环境变量 ADMIN_DATABASE_URL）
2. config.DATABASE_URL（通用 fallback）
3. 空 → 走 SQLite
```

### 1.3 劳务任务队列

**文件：** `bonus_platform/engine/labor/jobs.py`

**启用条件（jobs.py:23-30）：**

```python
def labor_worker_jobs_enabled() -> bool:
    mode = os.environ.get("SIGMA_LABOR_EXECUTION_MODE", "")
    if mode in {"worker", "workers", ...}:  → 启用
        return True
    if mode in {"inline", "legacy", "local", "off", ...}:  → 禁用
        return False
    # 未设置 mode 时：Vercel + production access → 启用
    return bool(os.environ.get("VERCEL")) and access in {"production", "prod", ...}
```

**后端选择（jobs.py:258-270）：**

```python
def _job_backend() -> str:
    backend = os.environ.get("SIGMA_LABOR_JOB_BACKEND", "").strip().lower()
    if backend in {"postgres", "postgresql", "supabase"}:
        return "postgres"
    if backend in {"mysql"}:
        return "mysql"
    # 根据数据库 URL 自动推断
    database_url = _job_database_url()
    if database_url.startswith("mysql://"):
        return "mysql"
    if database_url.startswith(("postgres://", "postgresql://")) or database_url:
        return "postgres"
    return ""  # → 降级到本地 JSON
```

**数据库 URL 优先级（jobs.py:286-293）：**

```
1. SIGMA_LABOR_JOB_DATABASE_URL
2. LABOR_DATABASE_URL
3. ADMIN_DATABASE_URL
4. DATABASE_URL
5. 空 → 本地 JSON 文件模式
```

**本地模式（jobs.py:13-14）：**

```python
LABOR_JOBS_DIR = OUTPUT_DIR / "labor_jobs"    # outputs/labor_jobs/
JOB_FILE = "job.json"
```

每个 Job 保存为 `outputs/labor_jobs/<job_id>/job.json`

**MySQL 模式的 `labor_jobs` 表结构：**

```sql
CREATE TABLE labor_jobs (
    id            TEXT PRIMARY KEY,
    run_id        TEXT NOT NULL,
    job_type      TEXT NOT NULL DEFAULT 'reconcile',
    status        TEXT NOT NULL DEFAULT 'queued',
    priority      INT NOT NULL DEFAULT 100,
    attempt       INT NOT NULL DEFAULT 0,
    max_attempts  INT NOT NULL DEFAULT 5,
    available_at  TIMESTAMPTZ,
    worker_id     TEXT,
    lease_expires_at TIMESTAMPTZ,
    heartbeat_at  TIMESTAMPTZ,
    error_code    TEXT,
    error_detail  TEXT,
    retryable     BOOLEAN,
    metadata_snapshot JSON,
    created_at    TIMESTAMPTZ,
    started_at    TIMESTAMPTZ,
    finished_at   TIMESTAMPTZ,
    updated_at    TIMESTAMPTZ
);
```

**任务领取逻辑（MySQL 模式, jobs.py:471-540）：**
- 使用 `UPDATE ... WHERE` + `ctid` 或行级 `SELECT FOR UPDATE SKIP LOCKED` 实现并发安全的任务领取
- 租约过期时间：120 秒（`JOB_LEASE_SECONDS = 120`）
- 最多重试：5 次（`maxAttempts = 5`）

## 2. 存储后端切换

### 2.1 海外劳务文件存储

**文件：** `bonus_platform/engine/labor/persistent_storage.py`

**启用的后端（persistent_storage.py:58-59）：**

```python
def labor_persistent_storage_enabled() -> bool:
    return labor_blob_storage_enabled() or labor_supabase_storage_enabled() or labor_obs_storage_enabled()
```

三个后端**互斥**，按代码优先级：

| 优先级 | Backend | 环境变量 | 状态 | 说明 |
|--------|---------|---------|------|------|
| 1（最高） | **OBS** | `SIGMA_LABOR_STORAGE_BACKEND=obs` | ✅ 主力 | 华为云对象存储，S3 兼容 |
| 2 | **Supabase** | `SIGMA_LABOR_STORAGE_BACKEND=supabase` | ⚠️ Legacy | 旧方案，仍可使用但不再推荐 |
| 3 | **Blob** | `SIGMA_LABOR_STORAGE_BACKEND=blob` | ✅ 可用 | Vercel Blob 存储 |

### 2.2 OBS 配置（当前主力）

**文件：** `bonus_platform/engine/labor/obs_storage.py`

**驱动：** `esdk-obs-python` (华为云官方 SDK，非 boto3)

| 环境变量 | 必填 | 说明 |
|----------|:----:|------|
| `SIGMA_LABOR_STORAGE_BACKEND` | ✅ | 设置为 `obs` |
| `OBS_ACCESS_KEY` | ✅ | 华为云 AK |
| `OBS_SECRET_KEY` | ✅ | 华为云 SK |
| `OBS_ENDPOINT` | ✅ | 如 `obs.cn-south-1.myhuaweicloud.com` |
| `OBS_BUCKET` | ❌ | 默认 `sigma-labor-runs` |
| `SIGMA_LABOR_STORAGE_ENV` | ❌ | 环境标签，默认 `local`，生产设 `production` |

**对象路径格式：** `labor-runs/<run_id>/<relative_path>`

**操作支持：**
- 上传文件（PUT with presigned URL）
- 下载文件（GET with presigned URL）
- 列出对象（按 prefix）
- 批量同步 run 目录
- 前端直传签名 URL

## 3. 环境变量汇总

### 3.1 本地开发

```bash
# 无需额外配置，所有值默认即可
# 数据库：自动使用 SQLite（outputs/sigma_workbench.db）
# 存储：本地磁盘（outputs/labor_runs/）
# 队列：本地 JSON（outputs/labor_jobs/）
```

### 3.2 生产环境（MySQL + OBS）

```bash
# ──── 数据库（三者共用同一 MySQL 实例）────
ADMIN_DATABASE_URL=mysql://<user>:<password>@<host>:3306/<database>

# 劳务队列专用 MySQL（不设则复用 ADMIN_DATABASE_URL）
# SIGMA_LABOR_JOB_DATABASE_URL=mysql://<user>:<password>@<host>:3306/<database>

# ──── 劳务队列模式 ────
SIGMA_LABOR_EXECUTION_MODE=worker
SIGMA_LABOR_JOB_BACKEND=mysql

# ──── 海外劳务文件存储 ────
SIGMA_LABOR_STORAGE_BACKEND=obs
SIGMA_LABOR_STORAGE_ENV=production
OBS_ACCESS_KEY=<华为云 AK>
OBS_SECRET_KEY=<华为云 SK>
OBS_ENDPOINT=obs.cn-south-1.myhuaweicloud.com
OBS_BUCKET=sigma-labor-runs

# ──── HRAS 壳子平台注册 ────
HRAS_SHELL_REGISTER_ENABLED=true
HRAS_SHELL_URL=<壳子后端地址>
HRAS_MODULE_KEY=hras-payroll
HRAS_MODULE_NAME=薪酬核算平台
HRAS_MODULE_FRONTEND_URL=<模块前端地址>
HRAS_MODULE_BACKEND_URL=<模块后端地址>
HRAS_MODULE_API_KEY=<从壳子管理员处获取>
```

### 3.3 生产环境（MySQL + Supabase Storage — 旧方案）

```bash
ADMIN_DATABASE_URL=mysql://<user>:<password>@<host>:3306/<database>
```

## 4. 切换判断流程图

### 4.1 数据库路径

```
ADMIN_DATABASE_URL 是否配置？
│
├─ 否 → SQLite（本地默认）
│      文件路径：outputs/sigma_workbench.db
│
├─ mysql://... → MySQL
│      └─ local_store.py:  Run 元数据 → MySQL
│      └─ admin_store.py:  Admin 权限 → MySQL
│      └─ jobs.py:         任务队列  → MySQL（需同时设 SIGMA_LABOR_JOB_BACKEND=mysql）
│
├─ postgresql://... → PostgreSQL
│      └─ admin_store.py:  Admin 权限 → PostgreSQL
│      └─ jobs.py:         任务队列  → PostgreSQL
│      └─ local_store.py:  ⚠️ 不支持 PostgreSQL，仍走 SQLite
│
└─ sqlite:///path → 显式 SQLite 路径
```

### 4.2 存储路径

```
SIGMA_LABOR_STORAGE_BACKEND = ?
│
├─ obs → 华为云 OBS（当前生产主力）
│      └─ 文件：obs_storage.py
│      └─ SDK：esdk-obs-python
│
├─ supabase → Supabase Storage（Legacy，仍可用）
│      └─ 文件：persistent_storage.py（内联 Supabase 函数）
│      └─ API：REST API by urllib
│
├─ blob → Vercel Blob
│      └─ 文件：blob_storage.py
│
└─ 空 → 本地磁盘
       └─ 目录：outputs/labor_runs/
```
