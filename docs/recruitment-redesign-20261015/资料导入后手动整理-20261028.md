# 资料导入后手动整理（2026-10-28）

用户要求先导完所有资料，再主动开始后台整理；根据已识别资料检查缺项，具备条件时突出按钮。

## 当前交互

- 资料页工具栏新增“整理资料并核算”。点击后启动既有 prepare 任务，保留停止、重试和实时进度。
- 上传资料、采用上月表、打开空月份及点击“查看核算明细”都不再隐式启动 prepare。上传仍会识别、保存并归类文件。
- 首次导入需要承接上月已确认结果时，通过本地 carry-forward 保留原有承接关系，不因此查询人事接口。
- 上传审批 PDF 或图片后不再自动打开核对窗口；通过资料卡片、待办手动进入。
- “一键同步国内及海外”仍是显式操作。整理或同步进行中、活动归档后，整理按钮禁用。

## 准备情况判断

按当前月份检查上月基础、本月花名册、原件读取错误、未采用快照、月份冲突、服务端标记的缺资料事项、领取人资料及已识别的体系外结果缺项。规则维护待决策、未涉及的离职审批和体系外资料不统一设为必填。

检查通过时按钮为蓝色，并短暂显示两轮动效；系统减少动态效果时关闭动效。存在缺项时显示最多三项提示，允许用户先点击整理已有资料，以便继续定向补查。

判断范围是已导入、已识别的人员和来源，不能据此证明未提交的文件已经全部提交。未对历史台账所有人员强制追加 API 覆盖要求。

## 验证

48 个相关 Node 测试通过；语法与 diff 格式检查通过。在浏览器测试页拦截网络响应，连续模拟导入 Excel、PDF，确认没有自动 prepare 请求和审批弹窗；手动点击后仅发出一次模拟 prepare 请求，并验证齐备动效、运行中和归档禁用状态。模拟请求未写入服务端业务数据。

当前活动实际检查仍有“补齐海外录用资料”，所以按钮未高亮。验证记录和截图见 `.audit/manual-intake-20261028/`。
