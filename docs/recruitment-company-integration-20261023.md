## 运行适配

新增工作台仍使用原引擎的 POSIX 文件语义，持久化方案为 **公司共享持久卷**；没有改造为 MySQL 活动表，也没有把 OBS 历史批次配置误用于新目录。API 所有实例必须挂载同一个支持文件锁、原子 rename 的 NFS/CephFS/GlusterFS 卷。`SIGMA_RECRUITMENT_DATA_DIR` 必须为该卷内的绝对路径；生产代码根据 Linux mountinfo 检查真实共享文件系统，未挂载时新工作台 API 返回 503，避免写入容器层或 `/tmp`。历史批次 API 不受该门槛影响。

该目录完整保存以下内容，备份应覆盖整个目录及隐藏文件：

- `recruitment_activities/`：活动、草稿、上传原件、解析文件、人工更正、特批、待办、确认版本及活动内试算。
- `recruitment_drafts/`、`recruitment_trials/`：原月度草稿及独立试算。
- `recruitment_shared_snapshots/`：不可变公共版本、月度索引、任务状态、定时设置和按日收据。

预览与生产必须使用不同的专用数据目录和已有 `SIGMA_LABOR_STORAGE_ENV` 环境标识，不能让预览调度器操作生产资料。不复制源仓库真实八月快照、活动或验收包作为生产种子。首次公司取数须在连接器接通后由授权流程执行。

`SIGMA_RECRUITMENT_SCHEDULER_ENABLED=true` 才启动招聘线程；原政策和社保任务生命周期保持原状。北京时间默认 08:00，保留源实现的本月、上月、未确认历史月份、启动补跑和持久收据。公共刷新与日调度在共享文件锁之外再取得现有 MySQL 的连接级 `GET_LOCK`，竞争者立即退出；进程退出释放数据库锁，持久化收据防止已完成日期重复执行。只读 HR 网络请求在进程崩溃的模糊窗口可能重试，不宣称外部接口具备 exactly-once 语义。

北森读取部署环境中的 `BEISEN_APP_KEY`、`BEISEN_APP_SECRET`；环境变量优先。公司模式不读取 `.env.beisen.local`，仅本地开发保留该文件回退。没有提交凭据或更改现有公司密钥值。

海外通过 `SIGMA_RECRUITMENT_OVERSEAS_CONNECTOR_URL` 和秘密 `SIGMA_RECRUITMENT_OVERSEAS_CONNECTOR_TOKEN` 连接已授权运行端；公司容器不回退到本机浏览器。客户端只接受 HTTPS、固定路径，无重定向，不复制浏览器 Cookie，校验来源月份、范围和原采集时间。登录失效、繁忙和连接错误如实失败，保留已有成功资料。

运行端程序为 `python -m scripts.recruitment_overseas_connector --port 8193`，默认只绑定 loopback，需由公司 HTTPS 网关转发固定 `/v1/recruitment/overseas-snapshot`。运行账户必须具备已授权的 Ego、有效 HRMS/OEHR 会话。运行端 Bearer 鉴权，只允许月度只读取数，限制输入范围并拒绝并发任务；不暴露任意 URL、脚本或审批执行接口。当前尚未部署或启动这个运行端。
