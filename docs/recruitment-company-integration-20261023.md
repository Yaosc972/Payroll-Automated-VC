日期：2026-10-23（Asia/Shanghai）。源提交 `5a845418c663d81640c9d4b7fb0c7a9e541b9ece`，公司基线 `d2eb77b5f86f0d65f56d2c31eaba45a0adf1fdca`。已核实生产为 #48、预览为 #49，二者 API 和算薪 worker 均 1/1 就绪；#49 尚未预览验收、审批或生产部署。招聘候选包含该正式工修复，发布前继续以平台实际状态为准。

## 保留的公司行为

现有登录、模块授权、MySQL、首页、正式工搬迁规则及其他模块保持。新 `/api/recruitment/` 入口沿用 recruitment 模块权限，匿名 401、无权限 403；页面沿用公司登录跳转。活动、公共快照、下载、定时设置、任务领取及回传均受保护。共享范围沿用原招聘模块业务范围。

首页招聘导航、卡片、模块列表及搜索进入 `/recruitment-activities.html`，旧批次通过 `/recruitment-history.html` 保留，原 OBS 批次存储不变。旧招聘页的增量样式独立在 `recruitment-history.css`，公共样式不改写。新页面保留公司字体、品牌、权限标记和反馈入口。

## 复用现有 MySQL 和 OBS

前一版本提出的共享卷和独立 HTTPS 连接器方案已移除。当前直接复用已配置的 `SIGMA_RECRUITMENT_STORAGE_BACKEND=obs`、公司 MySQL、私有 OBS 桶和凭据；不新增存储服务、挂载目录、外部取数入口或应用密钥。`AIDEPLOY_ENV` 在已有存储环境标签上自动区分预览与生产，新目录前缀、表和旧模块隔离。

`mysql/20261023_recruitment_state.sql` 是幂等、增量迁移，仅创建招聘状态、不可变版本清单、取消请求及浏览器任务表。接入既有 `scripts.migrate_company_features`，由平台迁移阶段执行，不在 Web 启动或请求中建表；不修改其他模块表。

`recruitment_persistence.py` 保留原文件引擎语义：每次请求从 MySQL 清单和已校验的私有 OBS 对象建立隔离工作副本，计算后先写不可变、按 SHA256 寻址的对象，再原子提交 MySQL 版本清单。进程退出或重新部署后可从同一清单恢复活动、原件、解析结果、人工更正、待办、确认历史、公共快照及定时设置。容器目录只用作可重建缓存；缺失或损坏对象返回失败，不伪造空活动覆盖保存状态。

MySQL 连接级互斥锁和版本条件更新保证同一招聘库只有一个有效写入者。同步过程中可以读取已保存版本；其他写入返回明确的忙碌提示。后台任务使用独立工作副本，发布进度及已成功保存的来源；跨实例取消通过独立 MySQL 请求传递。数据库连接失去锁后不能再发布旧状态。此版本验证范围为单文件 100 MiB、工作库文件总量 500 MiB。

## 复用海外原生接口和 Ego 登录

已核实当前授权 Ego 会话可进入 OEHR 花名册、HRMS Offer，并存在花名册查询和任职历史接口。公司应用已有凭据中没有对应的 HRMS/OEHR 服务凭据，因此不拿北森凭据或其他模块密钥去尝试访问。

服务器把按月、按工号和 Offer 编号限定的只读任务写入现有 MySQL。`scripts/recruitment_browser_worker.mjs` 在已登录的 Ego 中，通过工作台现有 HTTPS 地址领取任务，复用原 `recruitment_overseas_browser.mjs` 采集，再回传校验通过的原始快照。正常工作台登录和 recruitment 模块权限负责认证，无需新共享 token；临时任务租约用于防止并发领取和过期结果写入，不作为独立登录凭据。

浏览器端只主动访问现有工作台，不开放监听端口。快照经月份、请求范围、完整性和采集时间校验后存入私有 OBS，发布 MySQL 收据；过期租约、登录失效、范围不符和来源失败均不能变成成功快照。Cookies 与临时租约仅在内存中使用，不写入运行配置或日志。

运行方式（由 `ego-browser nodejs` 调用模块导出的 `run`）：提供当前受控 `spaceId`、已登录工作台的 `controlPage` 和停止文件。预览证书名称不匹配时，仅允许该应用已知预览 Host 通过证书有效的 AIDeploy 网关路由，保持 TLS 校验；生产直接走工作台同源 API。

取数节点需要 Ego 在线并保有有效的 HRMS/OEHR、工作台登录。休眠、退出或用户接管时暂停取数；任务会等待、超时或按租约重领，已有成功版本保留。不能把本机节点描述成公司 24 小时无人值守服务器；此限制在实际交付状态中明确记录。 领取任务时遇到网关 5xx 或已识别的临时网络错误，取数端保留运行并重连；登录失效、权限拒绝和浏览器控制释放仍停止。等待同一取数端期间每 5 秒重新报告状态，避免进度节流使界面停留在上一来源。

## 调度与验收

公司模式默认启动招聘调度线程，仍可用可选 `SIGMA_RECRUITMENT_SCHEDULER_ENABLED=false` 暂停进程侧调度；用户通过页面保存的 enabled 设置也继续生效。北京时间默认 08:00，范围为本月、上月和未确认历史月份，按持久化自然日收据补跑；完成日期不重复执行。只读 HR 请求在崩溃的模糊窗口可能重试，不声称外部接口 exactly-once。

本地完整回归及平台验证收据保存在 `.codex-artifacts/recruitment-integration-20261023.json` 和关联证据目录。真实 MySQL/OBS 读写、真实国内及海外同步、重复触发、活动采用版本、人工处理保留、换实例恢复和预览验收，以候选运行证据为准。本地模拟不能替代这些检查。

不导入源仓库真实八月验收包作为生产种子；旧八月业务准确性仍为 NOT VERIFIED，不能宣称可直接发薪。预览通过后按现有审批流程，将同一镜像晋级生产；最终“确认生产验收”留给用户。本次回滚点以发布前核实的健康版本为准，目前为 #48。
